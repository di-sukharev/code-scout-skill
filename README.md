# Code Scout

Чтобы дорогая модель не тратила свой дорогой контекст, она запускает дешёвого саб-агента, который ищет нужный код и приносит его на тарелке.

Вместо 50 файлов основная модель читает 5. Гениально.

## Установка

Отправьте агенту это сообщение.

```text
Установи скилл глобально https://github.com/di-sukharev/code-scout-skill
```

## Запуск

Напишите `<задача>, используй скаута`.

## Другие скиллы

- [Orchestration](https://github.com/di-sukharev/orchestration-skill) — выполняет задачи по очереди: новый саб-агент изучает код, пишет план, реализует задачу и запускает независимое ревью через Loop Code Review.
- [Loop Code Review](https://github.com/di-sukharev/loop-code-review-skill) — ревью только что написанного кода в цикле — саб-агенты без контекста в цикле находят и исправляют проблемы в активных изменениях.
- [Refactoring](https://github.com/di-sukharev/refactoring-skill) — профилактический рефакторинг кода — чистит код от легаси, лишних абстракций, слабых тестов и других жидких реализаций.
