# Code Scout

Саб-агент исследует текущую реализацию и приносит основному агенту короткий отчёт
со ссылками на код, тестами и открытыми вопросами. По умолчанию: Codex —
`gpt-5.6-luna`, Claude Code — `sonnet`. Модель можно указать в запросе.

Установка — отправьте агенту:

```text
Install this skill globally: https://github.com/di-sukharev/code-scout-skill
```

Запуск:

```text
Use $code-scout to find how authentication works before changing it.
```
